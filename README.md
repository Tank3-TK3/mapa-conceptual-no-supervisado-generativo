# Mapa conceptual: aprendizaje no supervisado y modelos generativos

Mapa conceptual de la **Actividad 3.1** de la materia *Aprendizaje Automático Avanzado*
(Maestría en Inteligencia Artificial, TecNM / Instituto Tecnológico El Llano Aguascalientes).

Muestra la jerarquía entre el aprendizaje no supervisado (K-means, PCA) y los modelos
generativos (GAN, VAE), sus conexiones teóricas, diferencias y sinergias.
